# Wellness Premium V3

Refonte visuelle mobile fidèle aux maquettes validées :

- Aujourd'hui : score bien-être unique, 4 indicateurs, coach, repas, défis/série/récompense.
- Nutrition : calories + macros, journal alimentaire, accès Recettes/Favoris.
- Plan : vue centrée sur un jour, navigation jour par jour, semaine complète et courses.
- Progrès : 4 KPI hebdomadaires, courbe de poids, mensurations et photos.
- Moi : réglages regroupés en Essentiel / Données / Plus.
- Le bouton + reste l'entrée universelle pour les ajouts.
- Les anciennes fonctions restent disponibles dans des feuilles modales premium.
- Les données et IDs existants sont conservés.
- Le planning supporte désormais aussi la Collation.

Cette refonte est HTML/CSS/JS uniquement et peut être publiée via le système OTA existant.
